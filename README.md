# توربو كلون (TurboClone) - النسخة التجريبية الأولى

مشروع Android كامل بلغة **Kotlin** و **Jetpack Compose** يمثل تطبيق العميل (Rider App) لتطبيق توصيل ركاب وطلبات، مستوحى من توربو + بريستو.

## ⚠️ اقرأ هذا أولًا - نطاق هذه النسخة

هذه أول نسخة تجريبية (Prototype) لغرض العرض والتجربة فقط، وليست جاهزة للنشر التجاري:

| الجزء | الحالة |
|---|---|
| تطبيق العميل (Rider App) | ✅ مبني بالكامل في هذا المشروع |
| تطبيق السائق (Driver App) | ⏳ غير مضمّن - يأتي في الإصدار القادم |
| لوحة الإدارة (Admin Panel) | ⏳ غير مضمّنة - تأتي في الإصدار القادم |
| Firebase (تسجيل دخول/قاعدة بيانات حقيقية) | ❌ غير مستخدم - كل البيانات وهمية (Mock) داخل الذاكرة |
| الخريطة | ✅ **حقيقية** - OpenStreetMap عبر مكتبة osmdroid + حساب مسافة/وقت/سعر حقيقي بالإحداثيات الفعلية |
| تسجيل الدخول | وهمي بالكامل - أي رقم وكلمة مرور تدخلك مباشرة |
| السائقون، الرحلات، المطاعم، المنتجات، المحفظة | بيانات وهمية مُولّدة داخل الكود (`MockRepository.kt`) |

## ⚠️ لماذا لم أستخدم Google Maps؟

استخدمنا خرائط **OpenStreetMap** (عبر مكتبة osmdroid) بدل Google Maps SDK، لأن مفتاح API المتوفر هو مفتاح **Geoapify** (مبني على OpenStreetMap) وليس مفتاح Google Maps. هذا الخيار عمليًا أسهل للتجربة لأنه:
- لا يحتاج ربط بطاقة بنكية.
- لا يحتاج تفعيل معقد أو قيود SHA-1.
- الخريطة حقيقية 100% (بيانات فعلية من OpenStreetMap).

## 🔧 كيف أشغّل المشروع؟

1. حمّل [Android Studio](https://developer.android.com/studio) (أحدث إصدار).
2. افتح المشروع (File → Open) واختر مجلد `TurboClone`.
3. انتظر حتى ينتهي Gradle Sync (يحتاج إنترنت لتحميل المكتبات أول مرة).
4. شغّل التطبيق على محاكي أو جهاز حقيقي (Run ▶️).

> ملاحظة: لم أستطع تشغيل Gradle build فعليًا في بيئة التنفيذ الخاصة بي (لا يوجد اتصال إنترنت هناك)، لذلك يُرجى بعد فتح المشروع في Android Studio إخباري بأي خطأ يظهر أثناء البناء حتى أصلحه فورًا.

## 🔑 مفتاح Geoapify

المفتاح موجود بالفعل في ملف `local.properties` (لا يُرفع لأي مستودع عام - أضف `local.properties` إلى `.gitignore`).

## 📁 هيكل المشروع

```
app/src/main/java/com/turboclone/app/
├── MainActivity.kt              # نقطة الدخول
├── TurboCloneApp.kt             # إعداد osmdroid
├── navigation/                  # التنقل بين الشاشات
├── data/
│   ├── model/                   # نماذج البيانات (User, Driver, Ride, Product...)
│   └── repository/MockRepository.kt   # كل البيانات الوهمية + حسابات المسافة/السعر الحقيقية
└── ui/
    ├── theme/                   # الألوان (أحمر + وضع داكن) والخطوط
    └── screens/
        ├── splash/               # شاشة البداية
        ├── auth/                 # تسجيل الدخول / إنشاء حساب
        ├── home/                 # الخريطة الرئيسية + اختيار من/إلى
        ├── ride/                 # طلب الرحلة، التتبع، التقييم
        ├── delivery/             # المطاعم، المنتجات، السلة
        ├── wallet/                # المحفظة وسجل العمليات
        └── profile/              # الملف الشخصي
```

## ✅ المميزات المطبّقة في هذه النسخة

- تسجيل دخول / إنشاء حساب (وهمي).
- خريطة حقيقية + تحديد نقطة انطلاق ووصول بالضغط على الخريطة.
- حساب مسافة/وقت/سعر تلقائي حقيقي (معادلة Haversine بإحداثيات فعلية).
- عرض سائقين وهميين قريبين على الخريطة.
- طلب رحلة → بحث عن سائق → قبول → تتبع لحظي (محاكاة حركة) → تقييم.
- إلغاء الطلب قبل قبول السائق.
- قسم توصيل الطلبات: تصنيفات، متاجر، منتجات، سلة مشتريات، دفع نقدًا أو بالمحفظة.
- محفظة إلكترونية: عرض الرصيد، شحن الرصيد، سجل العمليات.
- تصميم داكن بالكامل، لون أحمر أساسي، دعم RTL كامل للعربية.
